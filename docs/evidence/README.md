# Evidence

No application test, OAuth, benchmark or live-demo evidence exists yet.

Future evidence should include the date, exact version, expected and observed behavior, and whether it is real or simulated. Use only sanitized artifacts cleared for public sharing. Do not upload tokens, authorization codes, real private drafts or personal account screenshots. Follow the [validation plan](../engineering/validation.md) and [contest checklist](../contest/submission-checklist.md).

Documentation/skeleton checks are separate from application validation and must never be presented as working product proof.
