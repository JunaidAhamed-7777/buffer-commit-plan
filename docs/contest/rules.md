## Contest facts

[Event](https://buffer.com/api/commit) · [Official terms](https://buffer.com/api/commit/terms)

- Build window: 28 October through 13 November 2026. Cutoff: 13 November 23:59 Pacific, which is 14 November 07:59 UTC / 13:29 IST because Pacific is on standard time then.
- Solo entry is allowed. Entrants must be at least 18 or their local age of majority, whichever is higher. India is not listed among the excluded countries; all other personal eligibility conditions still apply.
- New work on an existing project can qualify if clearly identified. Only eligible contest-window work is judged. This is a new, independent plan; do not recycle prior submitted projects.
- AI-assisted work is allowed, subject to rights and originality obligations. Record actual assistance honestly.
- Equal judging emphasis: usefulness, execution/craft, originality. Minimum qualifying score is 9/15; usefulness breaks ties.
- Cash pool: $25,600 divided among up to 16 qualifying winners. Award and payout are not guaranteed. Field size is unverified.
- Judging is approximately 16–20 November; public availability must continue through judging. Winners are scheduled for 7 December. Plan hosting through that date unless organizers clarify otherwise.

## What a future entry needs

A hosted working app, OAuth authentication with Buffer, successful real API use, a demo no longer than two minutes, approximately 300 words covering problem/audience/API/next steps, and an app client ID. A personal API key alone does not satisfy the OAuth requirement. Public source code was not required in the rules reviewed; the owner has now authorized publishing this repository. This does not substitute for a working public app.
